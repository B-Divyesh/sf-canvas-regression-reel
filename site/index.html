Use it in a project

Build a local package before registry release

The npm registry release is not available yet. Build the included package tarball, then install it in your game project.

Canvas Regression Reel has no account, telemetry, cloud service, or artifact upload.

local package setup
npm ci
npm run build
npm pack
npm install --save-dev ./canvas-regression-reel-0.1.0.tgz playwright
npx playwright install chromium

The published package is a factory-managed release dependency.

Privacy and limits

Keep game frames on your machine

Reports embed local frames. Add masks before sharing reports with private or volatile areas.

The tool does not provide a test farm, asset hosting, or automatic fixes.

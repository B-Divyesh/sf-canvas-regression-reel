Plain-language policy

Privacy

Effective August 28, 2026

Canvas Regression Reel is local-first. The npm package does not include analytics, telemetry, accounts, or any artifact-uploading code.

What the tool handles

The CLI opens the URL you configure, captures the canvas checkpoints you name, and writes PNG files and an HTML report to paths on your machine. Reports may contain images from your game. User-defined mask rectangles are excluded from comparison and visibly redacted in the report.

What this site collects

This documentation site sets no cookies and stores no personal data in local storage. The interactive example runs entirely in your browser. Standard infrastructure logs may temporarily contain request metadata such as an IP address and user agent for security and reliability.

Your choices

Review reports before sharing them, add masks for private or volatile areas, and set your CI artifact visibility appropriately. Deleting the output directory removes locally generated run data.

Contact

For privacy questions, open an issue in the project’s public source repository without including private game assets or report files.

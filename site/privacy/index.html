Plain-language policy

Privacy

Effective September 5, 2026

Canvas Regression Reel is local-first. The package does not include analytics, telemetry, accounts, cloud services, or artifact uploads.

What the tool handles

The CLI opens the URL you configure, captures the canvas checkpoints you name, and writes PNG files and an HTML report to paths on your machine. Reports can contain images from your game.

Masked areas

Mask rectangles are excluded from comparison and redacted in report images. Review reports before sharing them.

What this site stores

The documentation site sets no cookies. The sample demo stores only its state under a demo: local-storage key. Reset demo replaces that sample state. It does not read or write your real data.

Requests

The site makes no analytics or tracking requests. Standard hosting logs can temporarily contain request metadata for security and reliability.

Contact

For privacy questions, open an issue in the public source repository. Do not include private game assets or report files.
